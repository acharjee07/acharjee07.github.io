From simulation to physical control

Built a control stack that converts image-space target error into joint commands for end-effector positioning. The same framework was validated in MuJoCo before deployment to a physical LeRobot SO-101.

Hardware demonstration from the project repository.

Control pipeline

  1. Derive analytical forward kinematics and the symbolic Jacobian.
  2. Detect the visual target with OpenCV and compute image-space error.
  3. Use Jacobian-based differential inverse kinematics to generate joint velocities.
  4. Monitor singularities and apply predictive joint-limit handling.

The project demonstrates a closed-loop perception-to-control workflow with simulation and hardware implementations. The demo uses a visually tracked target; it is not a learned general-purpose manipulation policy.
